# Task 3 - Cybersecurity Incident Simulation

## Objective
Simulate a cybersecurity incident by analyzing Windows Security logs to identify suspicious activities, detect Indicators of Compromise (IOCs), and recommend appropriate response and containment actions.

## Tools Used
- Windows Event Viewer
- Windows Security Logs
- Microsoft Word

## Task Description
The Windows Security logs were analyzed using Event Viewer. Relevant Event IDs were filtered to identify authentication events, process creation, and privileged logons. The collected evidence was documented and analyzed to determine whether any suspicious activity was present.

## Event IDs Analyzed
- **4625** – Failed Logon
- **4624** – Successful Logon
- **4688** – Process Creation
- **4672** – Special Privileges Assigned to New Logon

## Indicators of Compromise (IOCs)
- Multiple failed login attempts
- Successful authentication events
- New process creation
- Privileged account logons

## Response and Containment Actions
- Reviewed failed login attempts.
- Verified successful login events.
- Monitored privileged account activity.
- Investigated process creation events.
- Recommended continuous monitoring of Windows Security logs.
